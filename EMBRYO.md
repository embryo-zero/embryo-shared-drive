# Embryo Shared Drive

Embryo Shared Drive is Embryo-Zero's fork of [juicefs](https://github.com/juicedata/juicefs) (194da2a, commit 194da2a). It does shared file system on top of object storage.

- Our changes live on the `embryo` branch. The original license files (LICENSE) are unchanged.
- Legal notes: LEGAL.md. Dated list of our changes: CHANGES-EMBRYO.md.
